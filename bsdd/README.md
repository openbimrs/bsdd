# bsdd

Short package-name reservation for a possible future buildingSMART Data
Dictionary integration.

This package is a **pure re-export** of
[`openbim-bsdd`](https://crates.io/crates/openbim-bsdd), pinned to exactly the
same version. It defines no independent API or types.

```toml
# Choose one package; do not add both directly.
bsdd = "0.1.0"
# openbim-bsdd = "0.1.0"
```

## Status

**Reserved scaffold only.** The canonical package does not currently implement
an API client, data model, authentication, validation, or conformance behavior.
See the repository [capability table](https://github.com/openbimrs/bsdd#capability-status).
